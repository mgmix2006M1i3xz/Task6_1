Домашнее задание к работе номер 6

Условие задачи: Написать программу, которая выводит результат сравнения двух введенных пользователем чисел в виде математического выражения (X<Y или X=Y или X>Y).

1. Алгоритм и блок-схема.

Алгоритм:

Начало.
Объявить переменные X и Y.
Вывести приглашение и считать значения X и Y.
Проверить условие: X < Y?
Если «Да» — вывести X < Y.
Если «Нет» — проверить условие: X == Y?
Если «Да» — вывести X = Y.
Если «Нет» — вывести X > Y.
Конец.

2. Реализация программы

#include <stdio.h>

#include <locale.h>

int main() {

    setlocale(LC_ALL, "RUS");
    int X, Y;
    printf("Введите первое число X: ");
    scanf("%d", &X);
    printf("Введите второе число Y: ");
    scanf("%d", &Y);
    if (X < Y) {
        printf("%d < %d\n", X, Y);
    } else if (X == Y) {
        printf("%d = %d\n", X, Y);
    } else {
        printf("%d > %d\n", X, Y);
    }
    return 0;
}
